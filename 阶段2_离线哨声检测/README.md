## 工程验收与交接

电脑原型用真实WAV和带音轨视频跑通，核对自动适配、事件边界/分数定义、来源与模型版本、文件可读和定位；纠错实际删、补、改并重新导入，原预测保持。已知误报/漏报照实记录，不以识别精度门槛阻止原型交付。

板卡后续分别取得有效输入、持续处理、采样UTC与自动标签证据；调试录音与正常无音频落盘模式分开验收。读视频音轨不等于完成跨设备录像同步或自动片段链路，这些仍在聊天06另验。

电脑本地维护源码，阶段内存新增派生数据和独立输出；保留原始音视频、人工标注、模型和所有旧结果。当前继续“04｜板卡音频采集与哨声检测”，训练更新时再交接05。按[聊天交接说明](../docs/聊天规划与阶段交接.md)在子任务通过后主动告知依据、未覆盖项和下一任务，不自动启动后续开发或发送消息。
