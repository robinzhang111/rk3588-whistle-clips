- 11 个本地原件与下载 ZIP 中对应条目的 SHA256 全部相同；派生及图形抽查前后原件哈希一致。音频未逐字节与远程 ZIP 核对，不把本地 ZIP 一致性外推为远程音频完整性认证。

## 2. start/end、声道与边界

作者 Arne Hasselbring 的[2017 学位论文](https://hulks.de/_files/BA_Arne-Hasselbring.pdf)，印刷页 22–24（4.1 节），列出的 10 个文件与本地文件名、8 位、双声道、采样率及 51 个事件一致；明确说明用 Audacity 读取以 **Samples** 为单位的起止位置并写入 JSON，检测器只使用第一个声道。

配套 [WhistleLab](https://github.com/ahasselbring/WhistleLab)只读源码固定提交：`9a71c1d6d04c365784b1dbefd6764ab191bed17c`。未编译、运行或安装其依赖。

| 核查项 | 依据与本项目派生约定 |
|---|---|
| 位置单位 | WhistleLabel.hpp 定义样本范围；AudioChannel.cpp 按声道解交错，每路数组长度=总交错样本数/声道数。故位置是每声道样本帧索引，不是秒、字节或双声道交错偏移。 |
| 秒数 | `start_seconds = start / 原始采样率`，`end_seconds = end / 原始采样率`；44.1 kHz 与 48 kHz 分别换算，禁止统一除以 48000。 |
| 索引与边界 | 零起始索引，`[start,end)`。WhistleLabel.hpp 注释 start 为第一枚属于哨声的样本，end 为第一枚不再属于哨声的样本。允许 `end == nframes`。 |
| 声道顺序 | AudioFile.cpp 保持 JSON channels 数组顺序；AudioChannel.cpp 从 `samples[i * numberOfChannels + channel]` 读取。JSON 0→WAV 通道0（通常左），JSON 1→通道1（通常右）。未核实其物理麦克风朝向，不能把 left/right 解释为机器人左/右/前/后。 |
| 源码命中判据差异 | EvaluationHandle.cpp 的 insideWhistle 实际使用 `start < position < end`，严格排除起点；本项目存储/切片仍采用头文件的 `[start,end)`，不隐瞒这一实现与定义的差别。 |
| PCM | 8 位 PCM 按 uint8 读取，解码浮点为 `(value-128)/128`。不能按 int8 直接读取，不能直接用前一版仅支持16/24位的 inspect_audio.py 检查。 |
| coreStart/coreEnd | 本批有 22 条声道标注带 core 字段，其中2条为0/0。核查的 WhistleLab 版本只读 start/end，未确认 core 字段语义。原始对象完整保留，范围合法的 core 秒数仅供追溯，不用于主评价；0/0不当作时间零的真实事件。 |
| UTC | 没有可信绝对采集起点，全部 `absolute_utc_start=null`；文件名/文件修改时间不能填补 event_time_utc。 |

位置换算准确不等于人工边界具有一个样本的声学精度；STFT 图的时间分辨率和人工选择均有误差。

## 3. 右声道异常处理

文件：`LUnitedvsUPenn20170728Half2.wav`，48000 Hz，每声道41286000帧，时长860.125秒。

| 项目 | 原始位置 | 换算秒数 |
|---|---:|---:|
| 左右同条 start | 37570000 | 782.708333333 |
| 左声道 end | 37670000 | 784.791666667 |
| 右声道 end（异常原值） | 376700000 | 7847.916666667 |

右声道原 end 明显超过文件长度，官方 JSON 同样存在该值。派生层保留原对象、JSON pointer、原始 end 和 raw_end_seconds；`valid=false`，有效起止位置及正式秒级区间置 null，状态为隔离，不自动截到 EOF，也不替换为左声道 end。

`anomalies.json` 保留左声道 counterpart 与 `candidate_only_end=37670000`，`candidate_adopted=false`。它只是排查候选，不是已确认的右声道修正。

左右在候选区间均可见能量突增及约3 kHz附近结构，支持同一声学事件的合理推断。用户试听上下文片段后确认“能听到，但无法分别确认左右两路”；因此没有确认右声道精确 end，仍隔离。

主评价固定使用通道0；整条右声道不进入主指标。不得仅删除右声道坏标签后，把该区域重新视为负样本。未来若要做右声道辅助评估，应先复核/修订派生标注并建立新版本，不改原件，不将左右同一事件计作独立样本。

## 4. 派生成果

目录：`阶段2_离线哨声检测/data/bhuman2017-prepared-v1/`，引用根 `data/whistle` 原件，不复制全集、不重采样。

- `manifest.json`：10个文件的原路径、大小、SHA256、采样率/帧数、PCM/声道、来源、许可缺口、标签目标及分组建议。
- `annotations_seconds.json`：102条声道标注，保留全部原始字段/位置、来源 JSON pointer/hash、秒数、有效性和异常状态；101条范围合法，1条隔离。
- `annotations_seconds.csv`：用于查看的秒级表；完整原对象/来源以 JSON 为准。
- `anomalies.json`：1条主边界越界记录及未采纳的候选。
- `split_proposal.json`：按关联录音/比赛分组的建议，不是已冻结的最终方案。
- `integrity.json`：原件前后哈希和11条ZIP一致性结果。

主评价左声道共51个目标事件，原标注总时长52.621882秒；文件时长总和4928.371961秒（82.14分钟），并非以两个声道再翻倍计算。发布者完全标注标志为true，但本轮未逐段人工核验全录音，不能宣称所有未标注声音都已复核。

## 5. 抽查记录

抽查规则预先固定：每个文件首条标注（10组），加上异常文件末条与 WhistleTest_tuhhnao16 的 EOF 标注（2组），共12组/24个声道窗口；每组保留标注前后各1秒，遇文件边界截到有效范围。

每组已生成8位双声道原参数试听 WAV、波形与STFT图，以及原音频位置和片段哈希。片段是本地核查派生音频，不是假装新录音。目录 `outputs/bhuman2017-audit-20261011-01/spotcheck/`，清单为 spotcheck.json。

已逐张查看12幅图：所有抽查标注内均见明显能量上升和窄带频率结构，与样本位置解释相容；不是自动听辨结论，不证明所有51条都正确。异常区间的左右结构均支持事件存在，候选右end未采纳。EOF 标注 end=28116000 对应585.75秒，属于合法右开边界；音频在终点仍有尾部能量，终点可能受文件截断限制，不能当作完整自然结束的精确标签。

24个声道窗口中22个出现数字满量程值，部分图形具有明显削波形态（包括异常位置左路）。与作者论文描述的麦克风过载一致；保留这些样本，不按数据质量事后挑选删除，并记录定位/频谱失真风险。

人工听辨：用户已确认异常位置的立体声片段中能听到哨声；未分别确认左右，也未确认其余11组声音。听辨状态记录为部分完成。用 Windows 默认应用启动 WAV 两次均报“找不到应用程序”；未修改关联或安装播放器，随后提供音频预览。

HTWK_Dutch 的较短文件在较长文件的完整PCM字节流中未发现精确子序列。这只排除了该种逐字节包含关系，不能证明不同采集场次，仍按同比赛保守合组。不同文件整文件SHA256均不同，同声道/裁剪/转换文件依然不应随机跨组。

## 7. 评价约定草案（尚未执行）

任务标签是本场目标哨声；论文4.1说明尽量排除邻场哨声，IranOpen存在大量邻场哨声和广播。根据用户当前目标，邻场检测应作为误触发，而非补成正类。单麦克风是否能区分本场/邻场尚未验证，必须保留失败案例，不承诺靠AI必然解决。

后续检测输出需区分候选事件起止样本、估计起点和作出判定时所对应的输入样本位置；主评估不使用电脑接收时间或脚本返回时刻定位事件。

建议在开发前固定：

1. 同文件通道0内一对一匹配，不能一次预测同时命中多条真值，也不能把逐帧正响应当作多条独立事件。
2. 主指标用起点匹配：估计起点与标注start差的绝对值≤0.2秒作为初始容差建议，最大化匹配数量后最小化总起点误差；0.2秒是协议候选，不是已验证精度或验收目标，正式跑评价前需冻结。
3. 报事件级TP/FP/FN、Precision/Recall/F1、FP/完整评估小时、重复事件数；同一真值多次预测，除匹配的一条外计FP并标记重复，不能静默消除错误。检测器内部合并规则属于实现的一部分，只在开发/验证调整。
4. 对匹配事件报告起点误差的有符号值、绝对值、分位数和判定延迟；离线计算耗时与音频决策延迟分开。EOF事件的结束误差单独标为截断/不确定。
5. “每小时误触发”分母按单路完整录音时长计算，不用人为平衡的哨声/负例小片段时长，不因两声道增加而翻倍。此批目标区间仅约1.07%，普通帧准确率不能替代事件指标。
6. 如需与论文比较，额外报告其“真值区间内有任一响应即命中、假响应1秒内合并”的原生协议；严格开区间实现与本项目半开标签的差异写清。该辅助协议不替代项目起点定位和独立分组评价。

许可明确性、其余试听和任务场景泛化尚未齐备；本轮没有计算检测指标。
