# 先记录标签，再导入录像：流程模拟

此测试无需相机实时拍摄或麦克风。RK3588 先手动生成事件，以记录开始为录像第 0 秒，之后电脑读取一段已有视频并按经过时间截取。标签不对应该录像中的真实哨声；不能用于证明真实音视频同步或精度。

## 1. 在 MobaXterm 的板卡终端记录

用户希望使用板卡实体按钮时，按 [板载 REC 按键触发](./板载REC按键触发.md) 加入 `--board-button`，短按 REC 触发，Ctrl+C 结束。下方 m/q 操作仅保留作为键盘替代测试方式。

程序已部署在 `/home/basketclip-project/stage1`。使用板卡系统 Python：

```bash
cd /home/basketclip-project/stage1
/usr/bin/python3 -m basketclip record --session manual-001 --output data/manual-001/events.jsonl --alignment-output data/manual-001/alignment.json --video-seconds 0
```

启动后等待约 10 秒，输入 `m` 回车；再间隔几秒重复几次，最后输入 `q` 回车。程序显示各事件的模拟录像位置。选择一段长度覆盖这些位置的视频。

文件不会覆盖。下一次使用 `manual-002` 等新会话，并同步更换目录与命令参数。

## 2. 导出到电脑

在电脑 PowerShell（不是板卡终端）执行：

```powershell
cd C:\path\to\basketclip\阶段1_离线手动触发
scp -i "YOUR_SSH_IDENTITY_FILE" -o IdentitiesOnly=yes -r boarduser@192.0.2.10:/home/basketclip-project/stage1/data/manual-001 data/
```

先确认本地同名目录尚不存在，避免混用不同测试。也可通过 MobaXterm 左侧文件面板下载会话目录。

## 3. 导入录像并截取

电脑必须准备 FFmpeg 和 ffprobe。视频路径可直接使用已有文件，不必复制或修改原件。下面的 `你的录像.mp4` 必须替换成真实路径：

```powershell
python -m basketclip doctor
python -m basketclip extract --video "你的录像.mp4" --events data/manual-001/events.jsonl --alignment data/manual-001/alignment.json --output outputs/manual-001 --before 8 --after 5
```

如果输出目录已存在，换用新目录。越界事件会跳过，不能作为截取成功。

## 4. 验收范围

查看片段能否播放、事件位置与模拟时间计算是否一致、前后时长是否正确。本测试仅验证板端记录、文件传输和视频截取流程。真实同步标记、哨声检测、网络实时标签接收均未覆盖。
