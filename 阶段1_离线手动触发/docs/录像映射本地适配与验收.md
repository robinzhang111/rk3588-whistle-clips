# E录像映射与截取：本地合成限定验收

2026-10-14：E本地软件子任务通过。未连接板卡/相机/真实接收器，未部署/录音/运行模型，不处理整场，不猜真实录像拍摄UTC。真实B/C采样及跨设备录像映射待验收。

## 接口与范围

新增basketclip/mapped.py及simulate_mapped_video.py、tests/test_mapped.py，复用timing.event_position/clip_window、media.inspect_video/extract_clip和relative.sha，不改旧timing/media/relative/cli源码。固定按事件发生起点前5秒后3秒，头尾按视频有效范围截短，不按事件结束点计算。

映射schema=bounded-video-utc-v1，绑定session_id、source_video_sha256、kind、evidence、video_duration、video_first_pts、format_start_pts及intervals。kind为synthetic或外部验收的verified_video_capture；非空说明不是程序自动证明真实UTC。每个连续有效interval包含utc_start/utc_end、video_start/video_end和既有alignment；时间区间左闭右开、媒体范围不重叠且按时间顺序，区间端点必须与线性映射一致。interval之间的空白表示未知/缺失，不能插值跨越。映射比例可由原make_alignment双锚点构造，不自动从文件日期获取。

mapped_window(event, mapping)返回录像位置、截取范围、实际seek偏移和头尾截短标记。缺少/未知映射、会话不符、事件在缺失或范围外，或请求片段跨越连续区间边界，明确拒绝；不截出看似成功的不完整片段。即使相邻区间接触也不自动跨段拼接，需后续明确连续性依据。本轮只支持一个既有视频文件，不实现多文件拼接。

入口校验视频SHA256、容器起点/视频流起点和映射范围，再建立新输出目录；synthetic映射必须显式--synthetic-test，避免被当作真实拍摄证据。seek偏移=video_first_pts-format_start_pts，复用旧FFmpeg寻址方式。视频流start_time不独立证明首帧硬件拍摄UTC，实际首帧/PTS连续性需外部映射依据；不能仅凭这层元数据校验宣称自动发现所有缺帧。非零PTS偏移有软件测试，本次实际短视频首PTS为0。

输出manifest保留原事件、映射类型、来源哈希和completed/rejected/failed原因。FFmpeg失败会标failed，可能保留本次未完成衍生片段，不当成成功；输入及历史文件不删除。输出目录必须不存在，FFmpeg使用-n拒绝覆盖。

## 操作

项目根目录PowerShell，进程内设置路径，不改系统环境：

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) '阶段1_离线手动触发'
$env:PATH = (Join-Path (Get-Location) 'tools/ffmpeg-9.0.2-essentials_build/bin') + ';' + $env:PATH
& './阶段2_离线哨声检测/.venv-naodevils-infer/Scripts/python.exe' -B 阶段1_离线手动触发/simulate_mapped_video.py --output 阶段1_离线手动触发/outputs/mapped-video-新会话
```

模拟固定使用已有5710e5b0e5691924647f88c18a8174b6.mp4短视频37.708333秒，合成UTC起点2000-01-01、合成未知区间录像12～15秒，与实际拍摄时间和真实哨声无关。5条合成事件位置1/8/13/17/36秒：1/8/36生成3片段，13在缺口、17的前5秒范围跨缺口，两条拒绝且无片段文件。合成入口不带--synthetic-test时拒绝且不创建输出。原音频PTS异常记录保留，本轮不是重跑相对音频检测。
