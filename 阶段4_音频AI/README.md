固定现用模型使用 → 人工纠错积累 → 电脑训练/验证候选 → 新版本另存 → 验证部署 → 保留回退。运行中的模型不实时改变权重。

## 工作与验收

- 使用人工确认的正负标签；模型预测、未核查背景和不确定声音不直接作为正确训练答案。
- 训练/评价时按录音或比赛来源分组，复用阶段二已有数据与诊断，记录用途和来源暴露。用于可信比较的分组不作为电脑原型实施前置。
- 按失败案例选择原模型微调或小模型候选，以固定现用模型为对照；不预设架构或收益。用户2026-10-13确定后续板端默认NPU模型推理，候选部署须验证RKNN转换和实机兼容。
- 记录漏检、误触发、起止质量、耗时和资源及测试限制，阈值在相应开发/验证数据上选择。没有改善时保留负结果并保持原版本。
- 权重、输入预处理、阈值、事件规则共同记录版本；新模型另存，不覆盖现用/历史版本。
- 本地训练/验证后另存ONNX/RKNN派生版本，核查对原权重输出的数值/阈值/事件差异，再实测RK3588 NPU速度和实际声音，通过后才替换部署；保留上一NPU版本、原H5 CPU参考及可执行回退步骤，不兼容候选先保持现用NPU版本。
