# 02｜实体哨子单吹事件评价协议 v1

2026-10-16。协议定义固定，实际数据的本版人工放行未完成；**本轮只运行合成夹具，不运行模型或评分真实候选。** 机器合同：[protocol.json](./outputs/02_protocol_sources_20261016_03/protocol.json)，参考实现：[step2_protocol.py](./tools/step2_protocol.py)。复用阶段二 `evaluate_testbench_events.match`，不改检测器/v1。旧协议保留。

## 1. 评价单位和输入

同一原始录音内、同一原采样率网格的连续段分别评分；不跨录音、分段中断、未复核缺口或声道匹配。所有位置为整数样本，[start,end)。多声道按既有实际声道独立推理/逐窗OR形成一个事件流，人工跨声道同声只记一次，不倍增样本数或时长。

必须先绑定：录音与标签哈希、家族/风险组、协议/前端/规则/模型版本、原采样率和样本帧数、标签粒度、复核覆盖范围、冻结排除范围及其理由。预测输入须有合法start/end，原网格与22050模型网格通过既有source_start_sample/source_end_sample映射；不能混合两种网格。空、越界、非整数、NaN/Inf等输入拒绝，失败保留，不裁成合法值冒充原预测。

## 2. 三种不同评价轨

**A 自然单吹主轨。** 仅接受本版实体哨子任务已人工放行、可分辨独立吹哨及自然起点的参考。建议值0.2秒在本版作为首次开发评价的固定起点容差：tol=floor(0.2×原采样率)，绝对起点误差<=tol包含边界。依据是已有项目评价惯例和首次分离比较需要；不是从新分数选出，也不是人工边界精度证明。边界本身不可靠的事件不能用放宽tol补救，应先标uncertain/边缘并排除。0.1/0.5秒可预先列为补充敏感性分析，用同一冻结预测，不能替换主0.2秒或据此选阈值。本轮不计算这些成绩。

**B 发布者区间组历史轨。** B-Human继续原通道0、51组及旧protocol-v2.json合同；组内多吹额外预测可能计旧组重复，这是旧基准口径，不代表可听邻场/组内哨声为非哨声。不将旧指标混入A轨，不改变旧历史结果。单吹/本版全部实体哨子指标需单独人工派生及覆盖。

**C 点命中候选轨。** 排球人工点击和不同算法锚点分别报告。当前delta_point=null、status=not_released，不能继承0.2秒。先根据发布者算法/人工点击语义和少量不看模型分数的听辨确定误差范围，冻结新版本后才评分。建议点命中边：参考点落入预测区间扩展±delta_point；最大一对一匹配，第二目标最小化点到原预测区间的距离和，最后按稳定索引破平局。一个拖长预测最多命中一个点，不能吞多个点刷召回；同时报告预测持续时间、点差及歧义。它不是自然起点误差；无完整覆盖时未匹配预测仅称“未匹配”，不当FP，更不能算precision或FP/hour。此轨尚未实现为真实评分命令，本轮不为未知容差造默认值。

NPY逐窗分类只作另列的发布分类回归；无时序来源不能生成事件TP/FP/FN、重复或FP/hour。四类粒度不得混成总分。

## 3. 覆盖、排除和边缘规则：先冻结，后看结果

1. coverage是用户实际完整复核的连续原样本区间。其补集、uncertain范围、无法区分实体/嘴吹的范围、输入缺口和边缘截断事件为初始排除区。已确认non_whistle含气笛/嘴吹口哨等保留在有效背景，不因为难就排除。
2. 初始排除区左右各扩0.2秒，裁到真实段边界；保护值与本轨tol一致，不能为某个误报临时扩大。若扩展后与某条真值区间相交，排除该完整事件及其左右同宽保护区；重复到不再变化。**范围闭包只读取人工标签/覆盖，不读取预测。** 邻近独立事件因此可能退出主计分，必须列excluded_event_ids和理由，不能偷偷删FN。
3. 剩余有效区间按半开边界组成islands。真值完整区间必须处于一个island，且非clipped，才参与A轨。onset或offset截断一律退出主轨，避免只保留较容易的边缘子类；另列边缘数及描述性检出，不混算P/R。
4. 预测按**起点**所属island决定是否主计分。起点在排除区记ignored_prediction，不是TP/FP；起点在有效区则保留，哪怕预测终点跨排除边界。后者标boundary_crossing，不提供终点精度，避免把拖长误报整体丢掉。必须同时报告有效时长、排除时长/事件数、ignored数及跨界数，让排除对结果的影响可见。
5. 匹配仅在各island内，不跨mask缺口。真实输入中断在入口形成不同连续段，v1状态需重置，断口当边缘；不猜测缺失PCM或桥接音频。短于1024窗而没被推理的真实尾部，不因模型没看见而事后扣分母；可评价且完整真值仍参与召回。截断事件按前述规则单列。

一份文件只有候选confirmed而没有完整背景复核时，不能把其余区间填进coverage。范围/标签修改必须新版本且记录是否已看结果；看结果后修订可用于诊断，不能称原冻结集的独立成绩。

## 4. 一对一匹配与重复

每island将预测与真值按起点、原索引排序；建立|pred_start-gt_start|<=tol的边。复用现有时序动态规划，依次优化：最大匹配数量；最小绝对起点误差总和；匹配对按时间顺序排列后以原prediction/label索引元组作确定性平局选择。原索引由冻结输入顺序决定，不能按匹配成绩重新排列。保存全部配对，便于复查歧义。

每真值最多1TP；每预测最多1TP。未匹配有效真值全计FN，未匹配有效预测全计FP。相邻两次独立吹哨即使首尾相接也不合并；一个长预测跨两声最多1TP、另一声FN。评价器不替检测器合并碎响应。

duplicate_FP定义为：未匹配预测起点落在**某个已匹配真值[start-tol,end)内，或在该真值起点±tol内**。它包含同一较长目标内部超过0.2秒的碎响应。是FP的子集，不能从FP扣除；若对应多个已匹配目标，重复只计一次，解释归属按最近起点、再原标签索引。没有已匹配目标的两个误报不算目标重复。其余未匹配FP单列other_FP；晚于真值区间又超tol的碎响应可能不被操作性定义捕捉，仍是FP，不能冒称物理重复全部穷尽。

旧评价器的重复标志仅检查起点±tol。本版保留其匹配器，在阶段四参考实现中另加“真值持续区间内”重复统计，**没有更改v1检测规则或旧指标**。

## 5. 指标、分母与NA

| 指标 | 定义 |
|---|---|
| TP/FP/FN | 有效island内的一对一结果，另外报excluded/ignored及边缘数量 |
| precision | TP/(TP+FP)，无有效预测时NA |
| recall | TP/(TP+FN)，无有效真值时NA |
| F1 | 2TP/(2TP+FP+FN)，分母0时NA；有FN但无预测时F1=0，不伪造precision=0 |
| duplicate_FP | 上述操作性重复数，为FP子集 |
| duplicate_rate | duplicate_FP / 全部有效预测数量；无有效预测NA。不是“有重复的目标比例” |
| FP/hour | FP×3600 / 符合条件的连续单路有效秒数，包含重复FP；时长0或条件不满足NA并写理由 |
| 起点误差 | 只对A轨匹配且自然起点可靠的事件报signed error、MAE/中位数和样本数，同时列FN |
| 终点误差 | 仅自然终点可靠、预测未在EOF/中断收尾且未跨mask的匹配事件；否则NA，列排除数 |

FP/hour要求连续录音完整核查目标与背景，保持全部正常干扰，没有按哨声出现挑选片段；多声道不加倍，有效段并集只计一次。**当前篮球15短片是正例精选素材，FP/hour统一NA**，即使某短片已完整听过也不能将20秒折算部署误报率。B-Human/NPY/未完整标排球不因总时长长就满足新任务分母。未来合格连续背景可折算，但短时折算与实际长时测量仍分开报告。

0候选只是一种输出：有有效真值则全部FN，无真值时召回NA；不能称模型有效。不同数据轨、模型运行时/格式、标签版本分开报告。先报每录音/连续段和每家族计数；同轨可micro汇总TP/FP/FN和合格时长；macro均值必须列哪些NA被排除及有效组数。不把重叠窗口当独立n，也不从当前未知比赛关系的小样本编置信区间或显著性结论。研究达标阈值尚未设定。

## 6. 参考实现和验证范围

`score_segment`只接受已规范化自然边界轨的一个连续段、明确coverage/exclusions和本地整数tol；默认fp_hour_eligible=false。它不读预测文件、不自动导入旧人工标签、不加载模型、不作点轨评分，是协议可执行边界参考。实际基线阶段需先核对运行events.json原样本映射与新人工sidecar，再调用；不能直接把old kind=whistle批量转为本版confirmed。

11项小型合成测试覆盖贪心失配、容差边界、长哨碎响应、相接独立吹哨、长预测不能吞两声、最小误差选择、mask闭包与预测无关、不跨缺口、拖长预测保留、边缘排除、零分母及点标签拒绝、确定性平局。见[测试代码](./tests/test_step2_protocol.py)。这些只验证评价合同，不证明真实标签正确或模型改善。
