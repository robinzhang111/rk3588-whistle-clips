### 目标

让他人能理解用途、运行流程和验证结果，形成可信的简历项目。

### 工作内容与交付

- 编写安装运行说明、架构图、通信说明和测试方法。
- 固化两套演示：离线版“录像与标签导入 → 时间对齐 → 批量生成”；实时版“吹哨 → 标签上传 → 等待画面 → 生成片段”。
- 完成一次明确时长和条件的持续运行测试。
- 汇总定位误差、检测效果、保存成功率、资源消耗与已知问题。
- 保留原始数据来源和标注说明，区分实测指标与设计目标。
- 简历只填写实际完成的功能和实测结果，不列入尚未实现的 AI 扩展。
