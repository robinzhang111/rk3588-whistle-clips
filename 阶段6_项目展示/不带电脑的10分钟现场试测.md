## 现场操作卡

1. RK3588使用已验收采集通路和稳定供电。影石Ace Pro 2单独录像并保留音轨，不要求电脑、手机或网络。相机能录清声音由用户确认，板端这次的实际输入仍需检验。
2. 板卡上电，等待系统灯**慢闪（亮1秒、灭1秒）**。这表示等待REC，不是采集。开机默认heartbeat不能当慢闪就绪；启动失败也可能保留原灯态。未看到明确慢闪时，不靠盲按判断成功。
3. 相机开始完整录像。板卡**短按一次REC**，系统灯常亮表示已受理开始、正在启动或运行。启动失败会快闪。常亮不证明输入有效或已经识别到哨声。
4. 保持稳定供电与采集设备连接。从首次REC开始计时，600秒时请求正常停止，随后收尾；初始化也计入600秒。也可在首次按键至少0.75秒后再次短按REC提前停止。按住产生的重复事件不作新按键。
5. 正常收尾后系统灯熄灭；失败快闪（亮100毫秒、灭100毫秒）。灯号不能替代赛后status和日志验收。停止后保持供电至少15秒，再按原板卡正常关机方式操作。不要在常亮或正在收尾时断电。
6. 每次开机最多一轮，结束后再次REC不会开始。需要另一轮须重启，产生独立新会话；不复用或覆盖旧输出。日期只是本次试测前缀，实际会话还带Linux boot ID前8位。

**现场无需运行04电脑服务、播放页或旧空格启动器。** 本服务由systemd运行，不依赖SSH存活；SSH断开不会要求停止。本轮没有实际断开SSH后采集的证据。开机等待和物理灯号也尚需实际重启验证。

## 保存什么

板端目录：`/home/basketclip-project/stage2/outputs/core-field-20261015-01-<boot前8位>/`。

| 文件 | 用途 |
|---|---|
| `status.json` | REC控制状态、开始/停止的单调时钟及观察到的系统时间、停止原因、错误 |
| `capture/status.json` | 原运行器状态、窗数/候选数、处理报告、资源释放和输入增益 |
| `capture/candidates.relative.jsonl` | 相对样本位置候选及软件时间诊断，逐条flush/fsync |
| `capture/sampling-diagnostics.jsonl` | 原采样计数、ALSA状态和软件时钟观察；不是录音 |
| `capture/producer.log` | 采集适配器必要日志 |
| 同级`<session>.console.log` | 本次开机等待/运行的控制台和异常栈 |

**不保存连续录音、特征或逐窗分数，不上传，不需要电脑接收器。** 没有`events.jsonl`或ACK是本入口的预期行为；正式UTC标签仍被门禁阻止。板卡断电会丢失未落盘部分，保留异常现场，不把中断冒充正常停止。

Ace Pro 2保存完整视频及音轨。板端与相机总同步误差未知；REC、拍手、文件日期和模型候选都不能直接建立可靠UTC映射。没有独立依据时拒绝自动映射板端候选；赛后可另行授权对相机原音轨做同源检测和相对截片。本次不提前执行。

电脑连接方法、密钥位置见[阶段零SSH说明](../阶段0_环境准备/SSH连接说明.md)。只将密钥交给SSH客户端，不查看或复制密钥内容。诊断命令在板端运行：

```bash

```

根据最新会话读取根`status.json`与`capture/status.json`及同级console。等待状态没有capture目录是正常的。启动失败/快闪时保留文件，不删除重试，不停止其他采集。PCM占用时本入口拒绝开始，不抢占。

若启动后长时间不收尾，保留供电，回电脑后只给本会话`capture/STOP`创建停止标记；若进程卡死，保留日志检查，不宣称已释放资源。600秒是协作停止请求上限，不是对故障进程退出时间的硬保证。

如取消此试测的开机等待，在板端执行以下命令（正在采集时会请求结束本服务）：

```bash

```

## 赛后独立取回

回电脑恢复原直连连接。先只读确认实际会话已`closed`且`resources_released=true`；0候选仅代表本次未生成候选，不代表声音无哨声或识别准确。若failed仍保留全部文件供诊断，不按成功验收。

PowerShell执行，先将`$session`替换成实际目录名。目标存在即停止，换新取回目录，不能覆盖。

```powershell
$key = 'YOUR_SSH_IDENTITY_FILE'
$board = 'boarduser@192.0.2.10'
$session = 'core-field-20261015-01-替换boot前8位'
$remote = "/home/basketclip-project/stage2/outputs/$session"
$local = "C:\path\to\basketclip\阶段6_项目展示\outputs\field-return-01\$session"
if (Test-Path $local) { throw '目标已存在，保留原件并换取回目录' }
New-Item -ItemType Directory -Path (Split-Path $local) -Force | Out-Null
ssh -i $key -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes $board "cat '$remote/status.json'; cat '$remote/capture/status.json'"
# 确认已结束后，再执行下面两个独立下载命令。
scp -i $key -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes -r "${board}:$remote" $local
if ($LASTEXITCODE -ne 0) { throw '下载失败，保留部分文件，不覆盖重试' }
scp -i $key -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes "${board}:$remote.console.log" "$local\console.log"
if ($LASTEXITCODE -ne 0) { throw 'console下载失败，保留现场' }
ssh -i $key -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes $board "sha256sum '$remote/status.json' '$remote/capture/status.json' '$remote/capture/candidates.relative.jsonl' '$remote/capture/sampling-diagnostics.jsonl' '$remote/capture/producer.log' '$remote.console.log'"
Get-ChildItem $local -File -Recurse | Get-FileHash -Algorithm SHA256
```

逐文件比较两端SHA256；console在本地改名为console.log。记录哈希相同后才把下载当作一致原件。命令不删除、移动或上传板端结果；失败会话缺文件时如实记录，不造空文件。相机完整视频另外导入新的原件目录，不覆盖既有视频。
