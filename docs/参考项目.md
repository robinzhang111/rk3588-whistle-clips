# 开源参考与工具

2026-10-10 查询仓库介绍与官方文档。未在本项目设备上运行，不保证板卡兼容性，也不代表存在可直接部署的完整同类系统。

| 项目 | 阶段 | 参考范围与限制 |
|---|---|---|
| [FFmpeg](https://github.com/FFmpeg/FFmpeg) | 当前 | 视频信息、音频提取、片段截取；基础版使用其命令行工具 |
| [LosslessCut](https://github.com/mifi/lossless-cut) | 当前 | 参考剪切和播放流程，也可人工核对结果；不整体复制桌面系统 |
| [python-sounddevice](https://github.com/spatialaudio/python-sounddevice) | 音频采集 | PortAudio Python 接口；实际设备与采样时间映射需验证 |
| [Audacity](https://github.com/audacity/audacity) | 当前测试 | 查看音频和人工定位同步标记，不作为运行依赖 |
| [Arduino-FrequencyDetector](https://github.com/ArminJo/Arduino-FrequencyDetector) | 基础检测 | 频率检测与 whistle switch 示例；是 Arduino 项目，不是 RK3588 裁判哨声识别成品 |
| [MediaMTX](https://github.com/bluenviron/mediamtx) | 实时传输 | 实时媒体接入、录制与播放；不自动解决事件与画面时间对齐 |
| [RKNN Model Zoo](https://github.com/airockchip/rknn_model_zoo) | AI | 模型转换与推理部署参考；不保证适合哨声任务 |

直接使用第三方代码前检查许可证及依赖。先看 README 和与本模块直接相关的示例，不因仓库热度增加无关依赖。
