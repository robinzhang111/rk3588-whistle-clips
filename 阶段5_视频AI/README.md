# 阶段5：视频 AI 辅助复盘

> 当前为规划，尚未实现。

[项目首页](../README.md) · [整体路线](../分阶段开发方向.md)

### 目标

在已有事件片段上增加一项有明确用途的视频分析能力。

### 候选方向与取舍

| 候选方向 | 用途 | 前提与风险 |
|---|---|---|
| 人员检测与跟踪 | 提供位置与运动轨迹，辅助查看 | 人物尺寸、遮挡和交叉会影响效果 |
| 指定裁判手势识别 | 为事件生成可能的手势标签，方便分类 | 裁判必须可见，需要标注数据 |
| 简单动作候选标签 | 辅助检索特定动作片段 | 定义必须清楚，不能直接作为判罚结论 |

### 工作内容

- 先检查实际录像的清晰度、视角与遮挡情况。
- 只选择一项功能，明确输入、输出及用户如何使用。
- 优先离线处理事件片段，不立即要求整场实时分析。
- 将 AI 结果与原始视频分开保存，并支持人工核对。

### 验收与交付

- 使用独立场次的片段测试，并记录具体错误类型。
- 按选定任务评估识别或跟踪效果及处理耗时。
- 演示该功能如何帮助查找、分类或查看片段。
- 输出功能演示、评估报告和限制说明。

不把自动判定走步、阻挡与撞人等复杂判罚列为本阶段默认目标。

## 材料归属

本阶段新增代码、测试、操作说明与结果记录放在本目录。引用前阶段功能时明确依赖，不复制整套前阶段工程。原始数据与输出使用阶段内的 `data/` 和 `outputs/`，实施时按需创建；大体积材料不提交 Git。
