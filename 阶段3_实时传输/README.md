### 目标

将视频来源由赛后导入替换为实时视频流，电脑在比赛中录像并生成片段。

### 工作内容

- 确认相机可用的视频输出方式，选择网络视频流或 HDMI 采集之一。
- 实现电脑接收视频、持续分段录像和实际采集时间索引。
- 增加 RK3588 网络标签上传、接收确认、去重与短暂断连补发。
- 建立并实测实时视频与事件的时间映射，不沿用离线偏移。
- 片段任务等待后续画面齐全再生成，持续录像与片段处理分别运行。
- 保留离线导入功能，供录像复测和现场网络条件不足时使用。

### 验收

- 人为延迟标签发送，确认事件定位基于发生时间。
- 测量视频处理、传输和缓存影响下的最终定位误差。
- 检查重复事件、事件链路断连与补发。
- 检查视频断流时记录缺失区间，不能把不完整片段显示为完整成功。
- 检查跨录像分段截取、开场和结束边界、多事件等待队列。
- 在片段生成期间验证录像连续性，记录持续运行条件与结果。

### 交付成果

- 实时录像与哨声事件自动片段记录系统。
- 实时链路接入说明、网络事件协议和时间标定记录。
- 与离线版定位效果的对比及已知问题。

本阶段要求自动保存；现场自动播放仍为待定扩展，不作为默认验收条件。
